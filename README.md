# Лира — голосовой помощник

Веб-приложение (PWA) с распознаванием речи, синтезом речи и собственной обученной моделью понимания команд.

## Запуск (Windows)

1. Установите Python 3 с python.org (при установке отметьте **Add Python to PATH**).
2. Дважды щёлкните **start.bat**. Откроется браузер по адресу http://localhost:8765.
3. Нажмите кнопку микрофона и разрешите доступ к нему. Говорите: «Который час?», «Погода завтра в Москве», «Открой YouTube», «Запусти калькулятор».

Лучше всего использовать **Google Chrome** или **Microsoft Edge**: распознавание речи работает через сервис Google, нужен интернет.

macOS / Linux: запустите `start.command` или `./start.sh`.

## Как открыть как отдельное приложение

В Chrome/Edge нажмите кнопку **«Установить приложение»** в шапке (или значок установки в адресной строке). Лира появится в меню «Пуск» и на рабочем столе и будет открываться в своём окне без вкладок браузера. Для запуска программ окно `start.bat` должно быть открыто.

Если сайты не открываются по голосовой команде: браузер блокирует всплывающие окна. Нажмите значок блокировки в адресной строке → «Всегда разрешать всплывающие окна с localhost». Ссылка-кнопка в ответе работает в любом случае.

## Что умеет

| Намерение | Пример | Как выполняется |
|---|---|---|
| time, date | «который час», «какое сегодня число» | системные часы |
| weather | «какая погода завтра в Астане» | Open-Meteo API |
| open_site | «открой ютуб» | словарь сайтов |
| open_app | «запусти блокнот» | локальный сервер `server.py` (белый список) |
| search | «найди в интернете рецепт плова» | поиск Google |
| wikipedia | «что такое UML», «кто такой Абай» | API Википедии |
| greeting, goodbye, thanks, how_are_you, about, capabilities, stop | «привет», «что ты умеешь», «стоп» | готовые ответы |

Режим **«Слушать постоянно»**: помощник реагирует на фразы, начинающиеся с его имени («Лира, который час»).

## Модель

* `data/dataset.js` — обучающая выборка (283 фразы, 14 намерений).
* `nlu.js` — модель: TF-IDF (слова, биграммы, символьные триграммы) + softmax-регрессия, градиентный спуск с L2-регуляризацией, 200 эпох.
* `node train.js` — обучение из командной строки, сохраняет `data/model.js` и `data/report.json`.
* Вкладка **«Обучение модели»** — метрики, кривая обучения, матрица ошибок, проверка фраз, переобучение в браузере.
* Под каждым ответом есть кнопка **«исправить»**: выбранное правильное намерение добавляется в выборку, модель сразу переобучается.

Точность на отложенной тестовой выборке (20%): ~81%, macro F1 ~80%.

## Структура

```
index.html            интерфейс
style.css             оформление (светлая и тёмная темы)
app.js                логика: речь, диалог, навыки, интерфейс
nlu.js                модель машинного обучения
data/dataset.js       обучающие данные
data/model.js         предобученные веса
train.js              обучение из командной строки (Node.js)
server.py             локальный сервер + запуск программ
manifest.webmanifest  описание PWA-приложения
sw.js                 service worker (кэш, установка)
start.bat / start.sh  запуск
```
