Модель понимания команд

Softmax-регрессия (однослойная нейросеть) на признаках TF-IDF: слова, биграммы, символьные триграммы.

Кривая обучения

функция потерь (cross-entropy) точность на обучающей выборке

Проверить фразу

Качество по классам (тестовая выборка)

Матрица ошибок

Строки — истинный класс, столбцы — предсказанный.

Дообучение на своих примерах

Добавьте фразу и выберите намерение. Примеры сохраняются в браузере и учитываются при переобучении. Исправить ответ можно и прямо в чате.

    Обучающая выборка

    Если уверенность ниже порога, помощник переспросит, а не будет угадывать.

    О программе

    Распознавание речи — Web Speech API (сервис Google в Chrome/Edge). Синтез речи — встроенные голоса системы. Понимание команд — собственная модель, обученная на {N} примерах. Погода — Open-Meteo, справки — Википедия. Запуск программ — локальный сервер server.py.
